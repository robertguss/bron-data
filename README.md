# bron-data

The data of [Bron](https://github.com/robertguss/bron): texts, alignments, lexicon, provenance, and the rights registry. Code lives in the `bron` repo; this repo is the durable asset and is meant to outlive the software (Bron principle 1).

## Layout (CapiTainS conventions; see `bron/docs/text-model.md`)

```
data/                      TEI texts, one directory per textgroup, then per work
  bavinck/
    __cts__.xml
    gd/
      __cts__.xml
      bavinck.gd.ed1.xml        first edition (1895–1901)
      bavinck.gd.ed2.xml        second edition (1906–1911), base text of ed2
      bavinck.gd.ed2.bron-eng.xml   Bron's English of ed2
alignments/                stand-off TEI link files (ADR 0006)
  deferred.yaml            link targets whose edition files a later milestone adds
identifiers/               citation history (ADR 0004)
  redirects.yaml           identifiers that left a text, and what they became (append-only)
  edits.yaml               declared substantial changes under an unchanged identifier
lexicon/                   TBX termbase (ADR 0008)
provenance/                stand-off scores and flags (ADR 0009)
registry/                  works, source copies, rights statements (ADR 0012)
segmentation/              SRX rules
```

So far: the textgroup and work metadata for Bavinck's *Gereformeerde Dogmatiek*, the first-edition text (`bavinck.gd.ed1.xml`), the GD¹ ↔ GD² structural concordance, and the rights registry.

## Licensing (two kinds of content, two licenses)

- **Transcriptions of public-domain works, metadata, and the registry** are not Bron's to license. They are marked with the Public Domain Mark where the underlying work is public domain, and any residual rights Bron might hold in them are waived under **CC0 1.0** (`LICENSE-CC0`). Bron claims no rights in Bavinck's, Kuyper's, Calvin's or Augustine's words.
- **Content authored by Bron and its contributors** — translations, lexicon definitions and rationales, alignment judgments and annotations, documentation — is licensed **CC BY 4.0** (`LICENSE`). Attribution is to "Bron contributors" and, where recorded, to the named reviewer; see `CITATION.cff`.

Each file states which applies in its TEI header or front matter.

## Contributing

Open a pull request. Corrections to texts and translations are welcome from anyone; the `reviewed` state can only be set by a vetted reviewer (see `REVIEWERS.md`, to be added with the first release, and ADR 0009 in the `bron` repo). CI (`.github/workflows/validate.yml`) is live: every pull request runs bron's checks (TEI, CapiTainS, citation declarations, identifier stability, registry, alignment targets), compares citations with the base commit, and verifies the DTS resolver. A change that would break a citation cannot merge.

## Status

GD¹, the first edition of the *Gereformeerde Dogmatiek* (1895–1901), is in place as one TEI file: 56 sections, 582 subparagraphs, and 2,270 page breaks, each linked to its page in the DBNL scans. It is generated by `bron convert gd1` from the Project Gutenberg transcriptions; the TEI header records the `bron` commit that produced it, and re-running the converter at that commit reproduces the file byte for byte. Cite a passage as `urn:cts:bron:bavinck.gd.ed1:<section>.<subparagraph>`, for example `urn:cts:bron:bavinck.gd.ed1:3.2`. A sample check of the text against the scans follows. GD² arrives with milestone M3. See `bron/docs/roadmap.md`.
